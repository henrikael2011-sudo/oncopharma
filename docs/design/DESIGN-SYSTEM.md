# ONCOPHARMA — Design System v0.1

## Paleta aprovada (tokens iniciais)
- Teal profundo `#063F3B`: marca e Care escuro.
- Esmeralda `#15735D`: ação principal Care.
- Azul-petróleo `#0A344A`: Clinical.
- Dourado `#D7A858`: acentos, nunca único sinal de risco.
- Menta `#B9E1D0`: destaque acolhedor.
- Canvas `#F5F8F7`; texto `#152C32`; perigo `#B42318`.

## Identidade
- Care: casa, coração, proximidade e acolhimento.
- Clinical: bolsa de infusão **não identificada como sangue**, cruz de cuidado e conexão clínica.
- Marca-mãe: ONCOPHARMA. SVGs atuais são **interpretações vetoriais provisórias** da arte escolhida, pendentes de revisão visual final.
- Nunca utilizar ® sem registro confirmado.

## Experiência
- Care: uma tarefa por tela, texto simples, botões amplos, zoom, leitura fácil, suporte a cuidador.
- Clinical: organização densa porém legível, fonte dos dados, estados de pendência e validação humana.
- WCAG 2.2 AA como meta; testar contraste e tecnologias assistivas antes de declarar conformidade.
- Ícones jamais devem ser o único canal para informações críticas.
