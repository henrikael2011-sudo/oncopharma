# Inteligência clínica — M6

Arquitetura definida; **sem modelo de IA conectado**. Somente sugestões condicionais, nunca prescrição ou autorização de quimioterapia.

Pipeline exigido: (1) dados autorizados e temporalidade (2) regras determinísticas (3) recuperação de evidência versionada (4) verificação de citação/escopo (5) rascunho de sugestão (6) validação humana (7) auditoria. Se faltar evidência, abster-se. Alertas urgentes independem de IA.
